Install JobCairn.

JobCairn runs on your Mac and does its work through your own Claude plan. Only Claude is required. Chrome, Gmail and the voice are optional.

Download for macOS How to open it the first time

Windows and Linux coming soon. Using a coding agent? Get the install prompt.

Before you start.

macOS 13 (Ventura) or later
On an Apple silicon or Intel Mac. To check, open the Apple menu › About This Mac.
A Claude plan that includes Claude Code
Claude does the reading and writing through your own account. Its usage counts toward your plan.
Google Chrome (optional)
Only if you want JobCairn to read job boards in your own browser.
A Gmail account (optional)
Only if you want job email filed under each job and replies drafted for you.

By installing JobCairn you agree to the terms of use. The Privacy page explains what the app keeps on your Mac and what it sends to Claude.

Install with a coding agent.

Use Claude Code, Codex, Cursor or another coding agent? Paste this prompt into it. The agent follows the same steps as the guide below, asks before it installs anything, never handles your passwords, and leaves signing in to you. Read the prompt before you run it.

Install prompt 
Help me install JobCairn on this Mac. Before each step that downloads, installs or changes anything, show me the command and wait for my OK.

1. Check that macOS is 13 or later (sw_vers -productVersion). Stop if it is older. Check for Apple silicon with sysctl -n hw.optional.arm64 (1 means Apple silicon; 0 or nothing means Intel).
2. Find the latest release at https://github.com/JobCairn/jobcairn/releases/latest (https://api.github.com/repos/JobCairn/jobcairn/releases/latest lists its files). Pick JobCairn-<version>-arm64.dmg for Apple silicon, or JobCairn-<version>-x64.dmg for Intel.
3. Download that .dmg and SHA256SUMS.txt from the same release into ~/Downloads with curl. Check the .dmg with shasum -a 256 against its line in SHA256SUMS.txt. If they don't match, stop, delete the .dmg and tell me.
4. Mount the .dmg with hdiutil, copy JobCairn.app to /Applications, then unmount it. If copying asks for a password, stop and tell me.
5. Check for node (22 or later), Python 3.11 to 3.14 (python3.11 to python3.14; 3.15 isn't supported yet) and ffmpeg. Install only the ones that are missing or too old, with brew install node, brew install python@3.12 or brew install ffmpeg. If Homebrew isn't installed, stop and give me the official command from https://brew.sh to run myself, because it asks for my Mac password.
6. If the claude command is missing, install Claude Code with Anthropic's official command: curl -fsSL https://claude.ai/install.sh | bash (if https://docs.claude.com/en/docs/claude-code/setup shows a different command, show me both and wait for my choice).
7. Check the app's signature, read-only: codesign --verify --deep --strict /Applications/JobCairn.app and spctl --assess --type execute -vv /Applications/JobCairn.app. If either check fails, stop and tell me. Don't remove the quarantine attribute (no xattr) and don't change any security settings. Then tell me to open JobCairn from Applications myself. macOS may ask once if I'm sure I want to open it.
8. Never type or ask for passwords, app passwords or API keys. I'll sign in to Claude myself, in JobCairn under Settings › Connections.

When you're done, list what you installed and what was already there.

Seven steps, three of them optional.

  1. Download the right file

    Open the latest release and download one file:

    • JobCairn-<version>-arm64.dmg if About This Mac shows Chip (Apple M1 or later).
    • JobCairn-<version>-x64.dmg if it shows Processor (Intel).

    Before you open it, you can check the download.

    JobCairn is new, so your browser may warn that the file isn't commonly downloaded. Keep it only if you got it from github.com/JobCairn/jobcairn/releases, and check the download before you open it.

  2. Move it to Applications

    Open the .dmg, drag JobCairn into the Applications folder, then eject the disk image.

  3. Open it the first time

    JobCairn is signed with an Apple Developer ID and notarised by Apple, so macOS checks it before the first open.

    1. Open JobCairn from Applications.
    2. macOS says JobCairn was downloaded from the internet and asks if you're sure you want to open it. Click Open.

    You only see this once. After that, JobCairn opens like any other app.

    If macOS says it can't check JobCairn for malicious software, or that the app is damaged, don't open it. Delete it, then download it again from our releases page and check the download. Apple explains these messages in Safely open apps on your Mac.

  4. Set up Claude

    Install Claude Code with Anthropic's installer. Then, in JobCairn, open Settings › Connections and choose Set up next to Claude. The app checks that Claude Code is installed, opens Terminal so you can sign in to your own Claude account, and runs a short test in an empty folder. JobCairn never sees your login.

  5. Optional

    Explore the example

    On the first screen, choose Try example to open a made-up job search for Alex Example. Each page offers a short tour, and the help button (?) at the foot of the sidebar starts one any time. When you're ready, choose Start fresh to set up your own.

  6. Optional

    Connect Chrome

    To search SEEK, LinkedIn, Indeed and other boards in your own Chrome, open Settings › Connections › Search in my Chrome. It walks you through installing the browser helper (about 118 MB), turning on Chrome's remote control, and connecting. Searches only read ads. They never apply or message anyone.

  7. Optional

    Connect Gmail

    Open Settings › Connections › Email (Gmail). You turn on 2-Step Verification, create an app password, check that IMAP is on, then test the connection. Job emails are then filed under each job. Nothing is sent without your OK.

Verify your download.

Each release lists a SHA-256 checksum for every file, so you can confirm yours arrived unchanged.

  1. From the same release, open SHA256SUMS.txt.
  2. In Terminal, run: 
    shasum -a 256 ~/Downloads/JobCairn-*.dmg
  3. Compare the result with the line for your file. If they differ, don't open it. Delete it and download it again.
